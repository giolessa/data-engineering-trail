# Data Engineering Trail

A structured, documented path through the skills, tools, and concepts I'm building toward a data engineering role. This repo is both a study log and a portfolio — each folder holds notes, small exercises, and resources for a specific topic area.

## Why this repo exists

I'm learning data engineering step by step, and writing things down as I go — partly to keep myself honest about what I actually understand, and partly so anyone looking at this repo can see how I think and how I got here.

## Progress

- [ ] 01 — Foundations (SQL, Git, data modeling)
- [ ] 02 — Python for Data (pandas, ETL patterns, testing)
- [ ] 03 — Databases (PostgreSQL, NoSQL, data warehousing)
- [ ] 04 — Pipelines (orchestration, batch vs. streaming, Airflow)
- [ ] 05 — Cloud (AWS services, infrastructure as code)
- [ ] 06 — Big Data (Spark, partitioning, file formats)
- [ ] 07 — Projects (applied work tying it all together)

## Structure

Each numbered folder has its own `README.md` with:
- a plain-language explanation of the concepts covered
- small scripts or exercises where relevant
- links to the resources I used

`notes/` holds looser material — cheat sheets, one-off write-ups that don't belong to a single topic.
